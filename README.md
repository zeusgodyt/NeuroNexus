## 📝 TASK 1 - Google Form-like Web Form

This task involves creating a **responsive, Google Form-style web form** using **pure HTML and CSS only (no JavaScript)**. The goal is to collect basic user information in a clean, user-friendly format.

---

## 🚀 Features

✅ Collects the following user details:

- **Full Name** (Text Input)  
- **Contact Number** (Phone Input)  
- **Address** (Multiline Textarea)  
- **Company Name** (Text Input)  
- **Email Address** (Email Input)  
- **Department** (Select Menu with: HR, Sales, Development, Marketing, Others)  
- **Gender** (Radio Buttons: Male, Female, Prefer not to say)  
- **Submit Button**

---

## 🌟 Bonus Enhancements

- 🔘 **Hover effect** on the submit button  
- 🎨 **Different background color** for the form compared to the page background  
- 🧊 **Minimalistic box-shadow** on the form for an elevated visual appeal
